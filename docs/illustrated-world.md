# 水墨插画与文字减量 · 1.4.0+8

新增 32 张离线水墨淡彩插画：16 张地点、8 张奇遇、4 张匿名人物剪影、4 张创角／装备／炼丹／万世碑场景。使用内置 `image_gen.imagegen` 独立生成，完整提示词见 [illustrations-prompts.json](illustrations-prompts.json)。运行资源位于 `assets/illustrations/`，RGB WebP、最大 1024×512，合计 2,251,694 字节（约 2.15 MiB）。原始 PNG 只保留在开发工作区，不进入安装包。

修行、山河概览、地点详情、奇遇、人物详情与交谈、装备、炼丹坊市、交锋和万世碑接入插画。地图与因果画布保留可操作的原有绘制。图片作为装饰排除读屏，按显示宽度分档解码，缩略图解码为160像素，失败保留原文与按钮。深色主题采用暗纸淡墨与边缘渐隐，战斗背景透明度22%。

奇遇和事件详情默认四行叙述，可展开原文；长河默认两行摘要，点开详情查看。交谈默认最近两轮，早期记录折叠查看，数据库记录完整保留。装备列表使用两行摘要，替换对比与所有属性仍在详情完整显示。耗时、资源要求、危险、行动选项、战斗预兆和数值不会折叠。

`IllustrationResolver` 仅接受知识过滤后的 DTO，不读取 World；稳定 ID 选择变体，不调用游戏随机流。传闻／未知地点使用通用山水。AI 奇遇只采用已知当前位置，不通过生成文字猜测隐藏人物或地点。插画选择和展开状态不写入世界或只读人生档案。
