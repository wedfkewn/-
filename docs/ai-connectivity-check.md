# AI 连通性模拟检查

检查日期：2026-10-08。按用户选择，仅用假密钥、内存安全存储和模拟 HTTP 适配器测试，没有调用真实 API，没有产生 API token 消耗。

## 已修复

- 聊天请求发送前统一去除模型名、密钥首尾空白，避免与模型检测的鉴权行为不一致。
- 同一 API 基础地址检测后更换模型，可以直接使用已保存密钥测试；只含空白的密钥输入视为留空。地址末尾斜杠不影响密钥复用，其他目标路径或端口不能复用。
- 服务商变更确认同时检查域名与端口，未确认前不修改设置或安全密钥。
- 取消后丢弃迟到的成功响应；若响应已经带回用量，保留该用量但不记为连接成功。
- 退出天机设置页会取消连接测试，异步结果不再操作已销毁的页面或输入框。
- 在读取安全密钥期间取消，也会阻止后续发出模型检测或聊天请求。

## 验证结果

- 新增 7 项回归测试，涵盖协议字段、密钥复用、端口确认、迟到响应、页面退出和密钥读取期间取消。
- 原有 AI 测试覆盖模型检测、错误格式、鉴权错误、限流、超时、拒绝响应、用量缺失、取消、本地回退、事务回滚和过期 revision。
- `flutter analyze --no-pub`：无问题。
- `flutter test --no-pub --reporter expanded`：121 项全部通过。

此结果不代表真实服务商连通性、DNS/TLS、真实模型权限或手机 Keychain/安全存储已验证。真实服务商仍需玩家在 App 内填写 URL、密钥、模型，点击测试连接验证。本次未编译新版安装包，已有 IPA 不包含本次修复。
