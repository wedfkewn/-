# 页面交互检查与修复

日期：2026-10-08。检查范围包括主导航、存档与万世碑、创角、地图、成长、奇遇、交谈、因果图和天机设置。使用代码检查、纯 Dart 规则与 Widget 操作验证，没有调用真实 AI 服务。

## 已修复的问题

1. 恢复存档后，待处理奇遇在修行页没有直接入口。现在显示“处理奇遇”，处理前禁用普通修行；尚未结束的秘境也有继续入口。
2. 世界或奇遇中触发战斗，原页面仍停留，用户无法直接看到出手操作。现在战斗开始后关闭子页面并切到修行交锋，历史档案不触发该跳转。
3. “回到当前人生”只切换了数据，仍显示万世碑。现在在世角色返回修行，已结束或不存在的人生返回存档。
4. 查看旧档案时，当前活跃人生仍在世，却能进入新一世创角。现在创建入口根据活跃人生状态显示，规则层原有保护保留。
5. 地图定位清除了筛选条件却未清空输入框。现在输入文字和筛选同步重置。
6. 最后一段行旅触发奇遇后，剩余路线已清空，暂停提示也随之消失。现在待处理入口独立于剩余路线，奇遇可以直接处理，战斗或雷劫可以返回交锋。
7. 秘境内地点详情仍能点击规划路线，而规则拒绝。现在详情与主地图共用行动禁用条件。
8. 取消人物中心选择仍切入人物模式，标签与图谱不一致。现在仅选中已知 NPC 后切换，取消保留模式和中心；弹窗退出动画完成后再销毁输入控制器。
9. 删除密钥缺少操作锁和失败处理，重复点击、与保存交错或退出页面可能出错。现在先持久化关闭 AI，再删除密钥；禁用并发设置操作，捕获存储错误并允许重试，异步完成不访问已销毁页面。
