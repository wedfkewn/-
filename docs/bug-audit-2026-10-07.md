# Bug 检查记录：2026-10-07

检查范围为修仙 App 的规则、地图与成长、AI 行动与恢复、存档与死亡冻结，以及页面导航和共享弹窗。没有执行安装包编译或上传。

## 已修复

1. 创角保存失败后仍离开存档页；返回当前世界失败后也可能错误切换页面。导航现在仅在操作成功后执行。
2. AI 行动最终保存失败后，在当前会话恢复行动若发生死亡，档案列表未刷新。恢复死亡时先读取万世碑记录，再发布界面状态。
3. 寿元边界先结算死亡、后检查行动是否合法，导致无效命令也可能使角色死亡。现在在隔离副本中验证行动，非法行动不会推进时间或改变随机状态。
4. 安全存储读取失败时，天机设置一直停留在加载状态。现在显示可重试状态，避免在配置读取失败时覆盖已有配置。
5. 交谈请求期间离开页面，完成后仍清空已销毁的输入控制器。现在只在页面仍存在时更新输入框。
6. 横屏、键盘和大字体同时使用时，弹窗可用高度不足，标题与按钮可能溢出。共享弹窗使用实际剩余空间，并允许整块内容滚动。
